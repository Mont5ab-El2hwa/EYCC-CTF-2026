# Ghost in the Hall

## Description

The SOC team has detected suspicious activity in the network traffic, revealing that a machine has been compromised. Your task is to use Network Capture (PCAP) file and Threat Intelligence to determine the attack method, identify any malicious payloads, and trace the timeline of events.
